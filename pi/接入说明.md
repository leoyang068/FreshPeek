# 树莓派接入说明

当前原型默认使用树莓派用户 `leoy`，因此运行时文件位于 `/home/leoy/`。如果使用其他用户名，请同步修改脚本开头的路径常量。

## 1. 复制文件

在 Mac 的仓库根目录执行：

```bash
scp pi/*.py pi/*.txt pi/*.example leoy@YOUR_PI_HOST:/home/leoy/
```

## 2. 创建私有配置

登录树莓派后执行：

```bash
cp /home/leoy/fridge.env.example /home/leoy/fridge.env
cp /home/leoy/fridge_cloud.env.example /home/leoy/fridge_cloud.env
chmod 600 /home/leoy/fridge.env /home/leoy/fridge_cloud.env
```

编辑两个 `.env` 文件，填入自己的 API Key、Supabase URL、publishable key 和设备令牌。真实配置文件已经被 `.gitignore` 排除，不能上传到公开仓库。

## 3. 安装依赖

Picamera2 建议使用 Raspberry Pi OS 自带的软件包，再建立可访问系统包的虚拟环境：

```bash
python3 -m venv --system-site-packages /home/leoy/fridge-venv
/home/leoy/fridge-venv/bin/python -m pip install --upgrade openai numpy
```

## 4. 测试摄像头

```bash
rpicam-hello --list-cameras
rpicam-still -n -t 2000 -o /home/leoy/camera_test.jpg
```

## 5. 只测试识别

OpenAI 方向识别测试，不连接后端：

```bash
/home/leoy/fridge-venv/bin/python /home/leoy/fridge_openai_test.py
```

Qwen 测试版本：

```bash
/home/leoy/fridge-venv/bin/python /home/leoy/fridge.py
```

## 6. 运行完整链路

OpenAI 视觉识别并上传 Supabase：

```bash
/home/leoy/fridge-venv/bin/python /home/leoy/fridge_openai_production.py
```

Qwen 视觉识别并上传 Supabase：

```bash
/home/leoy/fridge-venv/bin/python /home/leoy/fridge_production.py
```

同一时间只能运行一个摄像头脚本。

## 云端上传与离线行为

- Pi 向 `ingest-event` 上传最小识别结果和本次照片。
- 后端负责保质期、合并、出库和数据库事务。
- 上传失败的事件保存在 `/home/leoy/fridge_pending/`。
- 下次连接恢复后，上传器会重试旧事件。
- 固定的 `event_id` 保证重试不会重复增删库存。

当前识别调用仍是同步的：模型返回前，摄像头不会捕捉下一次开门事件。快速连续开门所需的持久化事件队列属于下一版本计划。
